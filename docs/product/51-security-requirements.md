# 51. Security Requirements

Must include:

- HTTPS
- Private RDS
- Private S3 buckets
- Encrypted database
- Secure secrets
- RBAC
- API authentication
- Rate limiting
- File validation
- Upload size limits
- Audit logging
- Backups
- Prompt injection protection
- Access filtering before retrieval
- Data anonymization for sales history
