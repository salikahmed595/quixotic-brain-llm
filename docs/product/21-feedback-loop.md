# 21. Feedback Loop

After an answer:

```text
Was this useful?

👍 Helpful
👎 Not Helpful
```

For sales:

```text
Outcome

○ Sale closed
○ Sale lost
○ Customer still deciding
○ Follow-up required
```

Store:

- User question
- Retrieved knowledge
- AI answer
- Agent action
- Feedback
- Outcome

New experiences become searchable memory after validation.
