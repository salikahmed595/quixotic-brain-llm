# 40. API Keys

Each internal Quixotic product should have its own credentials.

Example:

```text
Quixotic Call Center
qx_live_callcenter_xxxxx

Quixotic CRM
qx_live_crm_xxxxx

HR Portal
qx_live_hr_xxxxx
```

Each key should support:

- App name
- Permissions
- Allowed departments
- Rate limit
- Created date
- Status
- Last used
- Revocation
